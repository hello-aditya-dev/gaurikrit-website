# Gaurikrit Website Master Pack

> The single source of truth for the Gaurikrit brand website — strategy, design, content, and implementation, packaged for an AI-driven build.

**Brand:** Gaurikrit — naturally derived *Haldi* (turmeric) and premium *paint* products.
**Build engine:** Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma.
**Aesthetic:** Turmeric gold meets disciplined Black & White. Premium, warm, trustworthy, industrial-grade.

---

## What's inside

```
Gaurikrit_Website_Master_Pack/
├── 00_SOURCE_ASSETS/      Original briefs, brochures, brand PDFs, working renders
├── 01_STRATEGY/           Locked decisions, information architecture, user journeys
├── 02_DESIGN/             Design system, page blueprints, component system
├── 03_MOTION_INTERACTIONS/ Motion spec, responsive & accessibility rules

├── 07_RESEARCH/           Official research, source inventory
├── 08_ZAI_PROMPT/         Master prompt for the AI build
├── ASSET_MANIFEST.json    Manifest of every asset used
├── README.md              This file
└── ZAI_MASTER_PROMPT_COPY_ME.md  The prompt that drives the build
```

## How to use this pack

1. Read `ZAI_MASTER_PROMPT_COPY_ME.md` end-to-end.
2. Skim `01_STRATEGY/PROJECT_DECISIONS_LOCKED` — these are non-negotiable.
3. Open `05_CONTENT_DATA/*.json` for the canonical copy and product catalogue.
4. Follow `06_IMPLEMENTATION/BUILD_PLAN` for the build sequence.
