# Client Inputs Required

These are the open items that need a brand stakeholder to confirm before v1.1.
Until confirmed, v1 uses sensible defaults documented in `05_CONTENT_DATA/`.

## Must-confirm (blocking for v1.1)
1. **Exact product SKUs & price bands** — v1 uses indicative ranges.
2. **Real certification numbers & issuing bodies** — v1 uses placeholder names (NABL, FSSAI, ISO 9001, GreenPro).
3. **Founder name + real quote** — v1 uses a composite "from the founder's desk" voice.
4. **Address & phone** — v1 uses a plausible Kolkata/India address placeholder.
5. **Hero & product photography** — v1 uses AI-generated visuals + CSS, replace before launch.
6. **Social handles** — v1 uses placeholder URLs.

## Nice-to-have (non-blocking)
- Real testimonial names + photos.
- Press kit (logos in SVG, color + mono).
- Sitemap + domain.
- Analytics property ID.
- Newsletter sender domain (SPF/DKIM).

## Sign-off process
1. Stakeholder reviews `/` in preview.
2. Walks the QA_ACCEPTANCE checklist.
3. Marks each "Client Input" as confirmed or supplies the real value.
4. Approves for the first public deploy.
